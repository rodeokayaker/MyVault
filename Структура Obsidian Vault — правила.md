# Структура Obsidian Vault — правила

Цель: единая логика хранения заметок, чтобы не плодить дубликаты и не класть активное в архив.

## Базовая схема папок

### `00_Inbox/`
**Входящие**: черновики, быстрые заметки, планы созвонов/встреч, то, что ещё не разобрано.
- После обработки либо остаётся как артефакт встречи, либо переезжает в проект/area.

### `Daily/`
**Ежедневники**: задачи/фокус дня, быстрые заметки, done.
- В Daily допускаются ссылки на проекты/areas/ресурсы.
- Если в Daily появляется новая сущность (локация/человек/тема) — лучше создать для неё отдельную заметку в правильном месте и линковать уже туда.

### `01_Projects/`
**Проекты** (имеют цель/результат, дедлайны, активные deliverables).
Примеры:
- `01_Projects/Smart Kayak/` — всё по Smart Kayak (в т.ч. `Patent/`, `Hardware/` и т.п.)
- `01_Projects/Kayak Moscow/` — всё по бизнесу KayakMoscow (маркетинг, локации и т.д.)

Правило: материалы проекта (презентации, заявки, чертежи, маркетинг) — лежат внутри папки проекта.

### `02_Areas/`
**Сферы ответственности / личное** (долгоживущие темы без явного «конца»).
- `02_Areas/Personal/` — личные задачи/люди/быт/логистика (BMX, отправки, нотариусы и т.п.)

Правило: активное личное — в `02_Areas/Personal/`, не в архив.

### `03_Resources/`
**Справочники/чеклисты/инструкции** (то, к чему возвращаемся многократно).
Примеры:
- `03_Resources/Finance/…` — финансы/крипта/процедуры
- Документация/рукбуки/гайдлайны

Правило: если заметка — это «как делать X» или «чеклист», это ресурс.

### `04_Archive/`
**Архив**: завершённое/историческое, больше неактуальное.
Правило: сюда уезжают только закрытые задачи/проекты/устаревшие версии.

### `90_Templates/`
**Шаблоны**.

## Правила линков и именования

### 1) Избегать двусмысленных ссылок
- Не использовать голые ссылки вроде `[[Project]]`, если есть несколько файлов `Project.md`.
- Лучше ссылаться явным путём: `[[01_Projects/Smart Kayak/Project|Project]]`.

### 2) Точка входа в проект
- У проекта должна быть «корневая» заметка с понятным названием.
  - Например: `01_Projects/Kayak Moscow/KayakMoscow.md`.

### 3) Локации/контексты проекта
- Локации проекта (Строгино/Архангельское/СберСити) живут внутри проекта:
  - `01_Projects/Kayak Moscow/Locations/…`

### 4) Редиректы допустимы
- Если в Daily/истории уже есть ссылка на общее имя, можно делать «заметку-указатель» в корне, которая ведёт на актуальное место.

## Быстрый выбор «куда положить новую заметку»
- Это **созвон/черновик/ещё не разобрано** → `00_Inbox/`
- Это **план дня/задачи сегодня** → `Daily/`
- Это **часть проекта с результатом** → `01_Projects/<Project>/…`
- Это **личное/быт/люди/долгие обязанности** → `02_Areas/Personal/…`
- Это **инструкция/чеклист/справочник** → `03_Resources/…`
- Это **уже не нужно активно** → `04_Archive/`
