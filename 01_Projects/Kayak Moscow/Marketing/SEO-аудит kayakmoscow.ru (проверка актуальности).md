# SEO-аудит `kayakmoscow.ru` — проверка актуальности (по чек-листу от 2026-03-16)

Источник/база: документ **«SEO-аудит kayakmoscow.ru»** от `2026-03-16` (прислан Иваном).  
Проверка выполнена: `2026-04-07` через HTTP-проверки (curl) и выборочный разбор HTML.

> Ниже — по каждому пункту: **актуально / исправлено / частично**.

## 1) Sitemap.xml устарел и вел на 404
**Статус: исправлено.**
- `https://www.kayakmoscow.ru/sitemap.xml` обновлён, `Last-Modified: Wed, 18 Mar 2026`.
- В sitemap присутствуют живые маршрутные страницы:
  - `/calendar/grebem-k-mostu-layt/`
  - `/calendar/na-zaliv-layt/`
  - `/calendar/kogda-zazhigayutsya-ogni/`
  - `/calendar/alye-parusa-i-r-khimka/`
- Битые URL из старого отчёта в sitemap больше не встречаются.

## 2) Индексируемые 404 и мусорные URL (в т.ч. /calendar/detail.php)
**Статус: в основном исправлено.**
- Случайный несуществующий URL теперь отдаёт `404` и в HTML есть:
  - `<meta name="robots" content="noindex, nofollow" />`
- `/calendar/detail.php` теперь отдаёт `404 Not Found` (раньше был `200 OK` с «Элемент не найден»).

## 3) Отсутствие canonical
**Статус: исправлено (на примере главной).**
- На главной странице присутствует:
  - `<link rel="canonical" href="https://www.kayakmoscow.ru/" />`
Рекомендация: выборочно проверить canonical на ключевых разделах и маршрутах (но базово проблема выглядит решённой).

## 4) Дубли Open Graph тегов
**Статус: исправлено (на примере главной).**
- На главной `og:title` и `og:description` встречаются по 1 разу.

## 5) Неверная структурированная разметка (Organization: фейковые контакты)
**Статус: исправлено (на примере главной).**
- JSON-LD `Organization` на главной содержит реальные данные:
  - адрес: `Строгинское шоссе, вл3`, индекс `123181`
  - телефон: `+7 495 128-21-52`

## 6) Внутренние ссылки на /privacy/ (404)
**Статус: исправлено.**
- `https://www.kayakmoscow.ru/privacy/` сейчас отдаёт `200 OK`.

## 7) Проблема с редирект-цепочкой и preferred host
**Статус: всё ещё актуально (P1).**
Наблюдается цепочка редиректов:
- `https://kayakmoscow.ru/` → `http://www.kayakmoscow.ru/` → `https://www.kayakmoscow.ru:443/` → `200`

Почему это важно:
- лишние редиректы = потери скорости + потенциальные проблемы с консистентностью индексации;
- редирект на `:443` выглядит неаккуратно.

Рекомендация:
- настроить 1 редирект: `https://kayakmoscow.ru/*` → `https://www.kayakmoscow.ru/*` (301) без промежуточного http и без `:443`.
