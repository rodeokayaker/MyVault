# ERP — инструкция для администратора

**Версия:** 1.0 | **Дата:** Март 2026

## Вход в систему

Откройте в браузере (или на телефоне): `https://admin.kayakmoscow.com`

Введите email и пароль. После первого входа смените пароль:
- Нажмите на своё имя в левом нижнем углу → **Профиль** → поле «Пароль»

> Система оптимизирована для работы с телефона — все основные функции доступны через мобильный браузер.

## Интерфейс: быстрый старт

### Боковая панель (левое меню)

| Раздел | Что внутри |
|--------|-----------|
| **Сплавы** | Конкретные запланированные выходы на воду |
| **Бронирования** | Все записи клиентов |
| **Клиенты** | База клиентов |
| **Персонал** | Гиды и сотрудники |
| **Назначения гидов** | Кто едет на какой сплав |
| **Корпоративы** | Корпоративные мероприятия |
| **Снаряжение** | Каяки, весла, жилеты |

### Закладки

| Закладка | Что показывает |
|----------|---------------|
| **Завтра** | Все завтрашние сплавы |
| **Ожидают оплаты** | Брони в статусе «Ожидает» |
| **Свободные места** | Будущие сплавы с незаполненными местами |
| **Корпоративы** | Предстоящие корпоративные мероприятия |
| **Назначения гидов** | Все назначения на сплавы |

## Ежедневная работа

### Просмотр завтрашних сплавов

1. Откройте закладку **Завтра**
2. Вы увидите все сплавы: маршрут, время, тип, сколько мест занято
3. Здесь же проверяете, назначен ли гид на каждый сплав

### Создание нового бронирования

1. **Бронирования** → **+ Создать**
2. Заполните:
   - **Клиент** — найдите по телефону или создайте нового
   - **Сплав** — выберите нужную дату/маршрут
   - **Тип сплава** — сборная / индивидуальная / ночная
   - **Взрослых** и **Детей** — количество
   - **Статус** → «Ожидает оплаты»
   - Цены заполните вручную или рассчитайте по тарифу
3. Сохраните (**Сохранить** вверху справа)

> После сохранения клиент автоматически получит подтверждение в Telegram (если у него указан Telegram ID).

### Создание нового клиента

1. **Бронирования** → **Клиент** → начните вводить телефон → **Создать «Имя»**
   или **Клиенты** → **+ Создать**
2. Обязательные поля: **Имя**, **Телефон**
3. Если корпоративный — включите **Корпоративный** и заполните **Компанию**

### Поиск брони

- **Бронирования** → поиск (лупа) → введите `KM-2026-0042`
- По телефону клиента: **Клиенты** → найдите клиента → раздел Бронирования внизу

### Изменение статуса бронирования

| Статус | Когда |
|--------|-------|
| `pending` — Ожидает оплаты | Только создали |
| `confirmed` — Подтверждена | Клиент оплатил |
| `checked_in` — Клиент на месте | Встретили на точке |
| `completed` — Завершена | Сплав прошёл |
| `cancelled` — Отмена клиентом | Клиент отменил |
| `cancelled_company` — Отмена компанией | Погода, форс-мажор |
| `rescheduled` — Перенесена | Перенесли на другую дату |

### Назначение гида на сплав

1. **Назначения гидов** → **+ Создать**
2. Выберите **Сплав**, **Гид**, включите **Старший гид** и **Подтверждён**
3. Или откройте карточку сплава и добавьте назначение внутри

### Перенос бронирования

1. Откройте бронь → смените **Сплав** на новый
2. Статус → `rescheduled`
3. Сохраните

## Клиенты и CRM

### История клиента

Карточка клиента → внизу связанные разделы:
- **Бронирования** — все брони клиента
- **Абонементы** — действующие абонементы
- **Теги** — метки для сегментации (VIP, корпоратив и т.д.)
- **Уведомления** — история отправленных сообщений

### Теги клиентов

Добавить тег: карточка клиента → **Теги** → **+ Создать**.

Примеры: `vip`, `абонемент`, `проблемный`, `корпоратив`

## Снаряжение

### Статусы

- `available` — доступно
- `in_use` — на сплаве
- `maintenance` — на ТО
- `damaged` — повреждено
- `written_off` — списано

### Выдача снаряжения

**Выдача снаряжения** → **+ Создать** → Сплав, Снаряжение, Участник, Выдано (дата/время).
При возврате — заполните **Возвращено**. Есть повреждения — включите **Повреждение**.

### Перемещение между точками

**Перемещения снаряжения** → **+ Создать** → единица, откуда, куда, дата.

### ТО и ремонт

**Обслуживание снаряжения** → **+ Создать** → тип, описание, стоимость.

## Расписание и слоты

### Статусы сплавов

| Статус | Значение |
|--------|---------|
| `scheduled` | Запланирован |
| `in_progress` | Идёт сейчас |
| `completed` | Завершён |
| `cancelled` | Отменён |

### Отмена сплава по погоде

1. Открыть сплав → статус → `cancelled` → заполнить **Погодная заметка**
2. Все связанные бронирования → статус → `cancelled_company`
3. Связаться с клиентами

### Создание нестандартного слота

**Сплавы** → **+ Создать** → маршрут, дата, время, тип, максимум мест. Поле **Шаблон** оставить пустым.

## Финансы

### Добавление платежа

**Платежи** → **+ Создать** → Бронирование, Сумма, Способ оплаты, Статус `completed`, Дата.

Способы: `card` (эквайринг), `cash`, `transfer`, `tinkoff_online`.

### Промокоды

**Промокоды** → **+ Создать** → тип (`percent` / `fixed`), Макс. использований, Даты действия.

## Корпоративы

**Корпоративы** → **+ Создать** → Клиент, Дата, Точка, Участников, Пакет услуг (JSON), Итоговая сумма.

Статусы: `inquiry` → `confirmed` → `completed` / `cancelled`.

## Зарплата гидов

**Зарплатные ведомости** → просмотр или создание. Статусы: `draft` → `approved` → `paid`.

## Частые вопросы

**Как найти бронь по телефону?**
Клиенты → найдите клиента → внизу Бронирования.

**Как посмотреть загрузку по точке?**
Сплавы → Фильтр → маршруты нужной точки + диапазон дат.

**Снаряжение на другой точке, как перекинуть?**
Перемещения снаряжения → создать запись откуда/куда.

**Клиент хочет перенос, бронь уже оплачена?**
1. Старую бронь → статус `rescheduled`
2. Создать новую на новую дату
3. Платёж остаётся на старой брони (связать вручную по необходимости)

**Как добавить нового гида?**
Персонал → **+ Создать**. Для доступа в Directus — попросите суперадмина создать учётную запись с ролью «Заведующий точкой».
