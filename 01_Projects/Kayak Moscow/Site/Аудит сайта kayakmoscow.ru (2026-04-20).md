# Комплексный аудит сайта kayakmoscow.ru

**Дата:** 2026-04-20  
**Область:** UX, продажи, контент, техническое SEO, конверсия

---

## Общее впечатление

Сайт визуально качественный, профессионально оформлен (студия SOMA design). Структура логичная, навигация понятная. Контент достаточный для принятия решения о покупке. **Однако** сайт работает скорее как красивая витрина, а не как продающая машина. Основные проблемы:

- Нет чувства срочности и социального доказательства
- Цены размытые (диапазоны вместо конкретики)
- Нет онлайн-записи с выбором даты — только форма «перезвоним»
- Техническое SEO запущено (битые ссылки, мусор в индексе, нет canonical)
- Нет блога/статей для привлечения органического трафика

## 1. КРИТИЧЕСКИЕ ОШИБКИ (исправить немедленно)

### 1.1 Опечатка в title главной страницы

```
Текущий: "Прогулки на каякахи и байдарках в Москве"
Нужно:   "Прогулки на каяках и байдарках в Москве"
```

Это первое, что видит пользователь в поисковой выдаче. Ошибка «каякахи» — серьёзный удар по доверию.

### 1.2 JSON-LD с фейковыми данными

Структурированная разметка содержит заглушки:
- Адрес: `ул. Красная площадь, д. 1` (вместо Строгинское шоссе, вл3)
- Телефон: `+7-499-123-45-67` (вместо +7 495 128-21-52)
- Индекс: `109012` (вместо 123181)

**Риск:** Google/Яндекс могут показать неверные контакты в сниппетах или снизить доверие к сайту.

### 1.3 Битые внутренние ссылки

6 мёртвых маршрутов до сих пор имеют ссылки с главной и из каталога:
- `/calendar/grebem-k-mostu-serebryanyy-bor-zhivopisnyy-most/`
- `/calendar/istra/`
- `/calendar/khochu-v-dzhungli-vokrug-lokhina-ostrova/`
- `/calendar/nemnogo-pokayachu-chistyy-zaliv-troitse-lykovo/`
- `/calendar/ogni-goroda/`
- `/location/arkhangelskoe/...`

Пользователь кликает — получает 404. Это прямая потеря конверсий.

### 1.4 Страница `/calendar/detail.php` открыта для индексации

Отдаёт 200 OK с текстом «Элемент не найден!», пустым title и без H1. Это SEO-мусор, который попадает в индекс.

### 1.5 404-страницы имеют `index, follow`

Поисковики индексируют страницы ошибок с дефолтным описанием «1С-Битрикс: Управление сайтом».

## 2. ПРОДАЖИ И КОНВЕРСИЯ

### 2.1 Что хорошо

| Элемент | Оценка |
|---------|--------|
| Чёткое УТП (малые группы, проф. инструкторы, безопасность) | ✅ |
| Подробное описание маршрутов | ✅ |
| Несколько CTA на страницу | ✅ |
| Мультиканальная связь (WA, TG, VK, MAX, телефон) | ✅ |
| FAQ для снятия возражений | ✅ |
| Подарочные сертификаты | ✅ |
| Раздел «О нас» с реальными людьми и регалиями | ✅ |

### 2.2 Что мешает продажам

#### Нет конкретных цен — только диапазоны

```
"3800–4200₽" — а сколько конкретно? Почему разброс?
```

Пользователь не понимает, от чего зависит цена. Нужно либо указать фиксированную цену, либо объяснить: «будни / выходные», «1-местный / 2-местный каяк» и т.д.

#### Нет онлайн-бронирования с календарём

Сейчас процесс: заполни форму → жди звонка → согласуй дату. Это барьер. Конкуренты дают выбрать дату и время прямо на сайте. Каждый лишний шаг = потерянные клиенты.

**Рекомендация:** Внедрить виджет бронирования (Yclients, Reservio, или хотя бы Google Calendar с доступными слотами).

#### Нет отзывов на страницах маршрутов

На главной упоминается «рейтинг 5.0 Яндекса», но нет ни одного конкретного отзыва или цитаты. Социальное доказательство — мощнейший продающий элемент.

**Рекомендация:** 
- Добавить 3–5 реальных отзывов с именами на каждую страницу маршрута
- Подключить виджет Яндекс.Карт с отзывами
- Добавить Schema.org `Review` / `AggregateRating`

#### Нет чувства срочности

Ничто на сайте не говорит «записывайся сейчас». Нет:
- Количества свободных мест
- «Осталось 3 места на 25 апреля»
- Ближайших дат с конкретным расписанием
- Сезонных акций или раннего бронирования

#### Нет визуального расписания

Пользователь хочет знать: «Когда ближайший сплав?» — и не может найти ответ на сайте. Нужен календарь с конкретными датами и временем.

#### Сертификаты — нет цены

Страница `/certificates/` не показывает стоимость сертификата. Пользователь должен угадывать или связываться. Это убивает импульсные покупки.

## 3. КОНТЕНТ И UX

### 3.1 Что добавить

| Элемент | Зачем | Приоритет |
|---------|-------|-----------|
| **Блог/журнал** | SEO-трафик по информационным запросам («куда поехать на каяке в Москве», «каякинг для начинающих») | Высокий |
| **Галерея/фото с прогулок** | Визуальное доказательство, эмоции, вовлечение | Высокий |
| **Видео** | 30-сек ролик на главном экране вместо статичного фото | Средний |
| **Страница «Как проходит сплав»** | Пошаговое описание для новичков (снимает страх) | Средний |
| **Сравнение маршрутов** | Таблица «какой маршрут выбрать» по параметрам | Средний |
| **Карта маршрутов** | Интерактивная карта всех маршрутов на Яндекс.Картах | Низкий |
| **Раздел для корпоративов** с кейсами | Названия компаний, фото, отзывы HR | Высокий |

### 3.2 Что убрать/исправить

| Проблема | Решение |
|----------|---------|
| FAQ на главной — только про зиму (раздевалка, холод, гидрокостюм) | Добавить летние вопросы: «Что взять с собой?», «Можно ли с ребёнком?», «Что если дождь?» |
| Нет страницы `/privacy/` (404), но на неё ссылаются | Создать страницу (она уже есть по адресу `/privat`? — проверить и сделать редирект) |
| Дублирование формы записи и формы сертификата на каждой странице | Оставить форму записи, сертификат вынести только на релевантные страницы |
| Текст «Ежедневно с мая по октябрь» — а сейчас апрель | Добавить информацию о старте сезона: «Сезон 2026 открывается 1 мая! Запись уже идёт» |

### 3.3 Навигация

- **Хорошо:** 6 пунктов меню, не перегружено
- **Проблема:** Нет пункта «Расписание» или «Ближайшие сплавы» — самый частый запрос пользователя
- **Проблема:** Подменю «Мероприятия» → «Готовые решения, Цены» — неочевидно что это корпоративы

**Рекомендация:** Переименовать «Сплавы на каяках» → «Каяки» (короче), добавить пункт «Расписание» с ближайшими датами.

## 4. ТЕХНИЧЕСКОЕ SEO

### 4.1 Sitemap — требует пересборки

**Текущее состояние** (после фикса от 18.03.2026):
- `sitemap-files.xml` — 7 основных страниц ✅
- `sitemap-iblock-13.xml` — пустой (0 URL) ⚠️
- `sitemap-iblock-14.xml` — 5 URL (calendar + 4 маршрута) ✅

**Что отсутствует в sitemap:**
- `/about/` — нет в iblock-14, но есть в files ✅
- SUP-маршруты (если есть отдельные страницы)
- `/privacy/` (или `/privat/`)

**Что лишнее:**
- `sitemap-iblock-13.xml` пуст — можно удалить из индекса

### 4.2 Отсутствует `<link rel="canonical">` — на ВСЕХ страницах

Это значит:
- Поисковик сам решает, какую версию URL считать основной
- `www` vs `non-www` не разрешено на уровне страницы
- Дубли контента не консолидируются

### 4.3 Дублирующиеся Open Graph теги

На каждой странице два набора `og:title` и `og:description`. Соцсети берут непредсказуемый вариант при шаринге.

### 4.4 Цепочка редиректов

```
https://kayakmoscow.ru/ → http://www.kayakmoscow.ru/ → https://www.kayakmoscow.ru:443/
```

Два хопа вместо одного. Нужно настроить прямой 301 с `kayakmoscow.ru` на `https://www.kayakmoscow.ru/`.

### 4.5 Нет meta description на страницах маршрутов

Все 4 живые маршрутные страницы имеют дефолтный description от Bitrix. Поисковик генерирует сниппет сам — это неконтролируемо.

### 4.6 Нет `<link rel="canonical">` и OG на детальных страницах маршрутов

Ни canonical, ни корректных OG-тегов. При шаринге ссылки на маршрут в мессенджере — превью будет некорректным.

## 5. МОБИЛЬНАЯ ВЕРСИЯ

Сайт адаптивный (определяет устройства через JS). Однако:

- Формы длинные — на мобильном нужно много скроллить
- Нет «click-to-call» на номере телефона (проверить)  
- WhatsApp-ссылка должна открывать чат сразу с предзаполненным сообщением
- Кнопка «Записаться» должна быть sticky (закреплённой) при скролле на мобильном

## 6. КОНКУРЕНТНЫЕ ПРЕИМУЩЕСТВА — ЧТО УСИЛИТЬ

Сайт уже показывает сильные стороны, но их можно подать ярче:

| Факт | Как усилить |
|------|-------------|
| 20 000+ участников | Счётчик на главной: «Уже 20 347 человек прокатились с нами» |

| Рейтинг 5.0 | Виджет отзывов Яндекс.Карт + звёзды в Schema.org |

| Малые группы (до 6 чел.) | Подчеркнуть: «Не толпа — максимум 6 человек. Вас услышат» |
| Безопасность (МЧС) | Бейдж/иконка «Инструкторы сертифицированы МЧС» на каждом маршруте |

## 7. РЕКОМЕНДАЦИИ ПО ПОВЫШЕНИЮ КОНВЕРСИИ

### Быстрые победы (1–2 недели)

1. **Исправить опечатку в title** главной страницы
2. **Исправить JSON-LD** — вписать реальные контакты
3. **Убрать битые ссылки** с главной и каталога
4. **Добавить 3–5 отзывов** на главную (цитаты + имена)
5. **Указать конкретные цены** (будни/выходные) вместо диапазонов
6. **Добавить «Ближайшие сплавы»** блок на главную с датами
7. **Поставить noindex на 404** и `/calendar/detail.php`
8. **Добавить canonical** на все страницы
9. **Создать `/privacy/`** (перенаправить с `/privat` если надо)

### Средний приоритет (1–2 месяца)

10. **Внедрить календарь бронирования** (выбор даты и времени онлайн)
11. **Написать уникальные title/description** для всех маршрутов
12. **Добавить Schema.org `Event`** на страницы маршрутов (для расширенных сниппетов)
13. **Удалить дублирующий OG-блок** из шаблона
14. **Упростить цепочку редиректов** до одного 301
15. **Добавить блок «Для кого этот маршрут»** с иконками (новички / семьи / спортсмены)
16. **Сделать sticky CTA** на мобильных
17. **Добавить видео** на главный экран (15–30 сек., атмосферное)

### Стратегические (2–3 месяца)

18. **Запустить блог** (5–10 статей для SEO-трафика)
19. **Сделать страницу кейсов** для корпоративов (названия компаний, фото, результаты)
20. **Подключить CRM** для автоматизации записи и напоминаний
21. **Настроить email-воронку** (запись → напоминание → отзыв после поездки)
22. **Добавить программу лояльности** («Каждый 5-й сплав — скидка 20%»)
23. **Интегрировать UGC** (фото клиентов из соцсетей на сайт)

## 9. ИТОГОВАЯ ОЦЕНКА

| Категория | Оценка | Комментарий |
|-----------|--------|-------------|
| Дизайн и визуал | 8/10 | Красиво, профессионально, атмосферно |
| Контент | 6/10 | Достаточно, но не продающий. Нет историй, отзывов, кейсов |
| UX / удобство | 6/10 | Нет календаря, нет конкретных дат, формы длинные |
| Техническое SEO | 4/10 | Битые ссылки, мусор в индексе, нет canonical, ошибки в schema |
| Конверсионность | 5/10 | CTA есть, но нет срочности, соц. доказательств, конкретики в ценах |
| Мобильная версия | 7/10 | Адаптивная, но нет sticky CTA и оптимизации форм |
| Доверие | 7/10 | Есть реальная команда, опыт, но нет отзывов и кейсов на сайте |

**Общая оценка: 6.1 / 10**

Сайт — хорошая основа, но он «рассказывает» вместо того чтобы «продавать». Главный рычаг роста — добавить конкретику (даты, цены, отзывы, свободные места) и убрать технический мусор из SEO.

## 10. ТОП-5 ДЕЙСТВИЙ С МАКСИМАЛЬНЫМ ЭФФЕКТОМ

1. **Добавить блок «Ближайшие сплавы» с датами и кнопкой записи** — снижает барьер входа
2. **Разместить отзывы на главной и страницах маршрутов** — повышает доверие
3. **Исправить технические ошибки SEO** (P0 из SEO.md) — перестать терять позиции
4. **Указать конкретные цены с объяснением** — убирает неопределённость
5. **Внедрить онлайн-бронирование с выбором даты** — сокращает путь до покупки
