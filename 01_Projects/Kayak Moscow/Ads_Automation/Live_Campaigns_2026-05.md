## Креативы для РСЯ (что и как делать Ивану)

РСЯ-Wide (#3 / 709893520) сейчас имеет **1 текстовое затравочное объявление** — этого недостаточно для нормальной работы РСЯ. Без графики и видео Yandex показывает редко и плохо. Нужно добавить:

### Что подготовить

**Статичные баннеры** (обязательно ≥3 разных, все JPEG/PNG ≤4 МБ):

| Формат | Размер (px) | Где показывается |
|---|---|---|
| Квадрат 1:1 | 1080×1080 | мобильные ленты, sidebar |
| Широкий 16:9 | 1920×1080 | главные блоки на сайтах |
| Вертикальный 9:16 | 1080×1920 | мобильные сторис |
| Дополнительно 4:3 | 1200×900 | классические inline-блоки |

**Видео-ролики** (опционально, но сильно поднимут CTR):
- 16:9 (1920×1080), MP4, ≤30 секунд, файл ≤30 МБ.
- 2-3 ролика разной длины: 6, 15, 30 сек.
- Сюжет: живая прогулка на каяке/SUP по Москве-реке, инструктор, улыбки, в финале логотип + телефон + сайт.

**Контент идеи (что показать на креативах):**

| Слой | Что |
|---|---|
| Главный визуал | Каякер/SUP-серфер на воде с видом на Москву (Серебряный бор, мосты, набережная) |
| Текст overlay | «Прокат каяков и SUP / от 2500 ₽» |
| Лого | «kayak moscow» |
| CTA | «Забронировать» / «Подобрать дату» |
| Цвета | Сине-голубая палитра воды + жёлтый/оранжевый акцент |

### Где взять/сделать

- **Свои фото с прогулок** — лучше всего, аутентично, бесплатно. Папка кейс-фото за 2024-2025.
- **Сток** для widescreen фоновых — Unsplash «kayak», «moscow river».
- **Canva/Photoshop** — для текстовых overlay'ов и логотипа.
- **CapCut/Premiere Pro** — для видеомонтажа.

### Как загрузить (UI Direct'a)

1. https://direct.yandex.ru → войти под `kayakmoscow@yandex.ru`.
2. Меню «Библиотека» → «Креативы» → «+ Добавить».
3. Загрузить файлы (каждый формат отдельно). Yandex проверит размер и качество.
4. После одобрения креативов в Библиотеке: «Кампании» → выбрать **[2026] РСЯ-Wide** → AdGroup **AG-1 / РСЯ-Wide** → «+ Добавить объявление».
5. Выбрать тип:
   - **Графическое** — для статичных баннеров.
   - **Видео** — для видео-роликов.
6. Заполнить:
   - **Заголовок**: «Прокат каяков и SUP в Москве» (≤56 симв)
   - **Доп. заголовок**: «Группы до 6 чел., от 2500 ₽» (≤30 симв)
   - **Текст**: «Прогулки 1.5-4ч с инструктором. Снаряжение в цене. Бронь онлайн.» (≤81 симв)
   - **Ссылка**: `https://kayakmoscow.ru/?utm_source=direct&utm_campaign=rsya_wide&utm_medium=cpm&utm_content=banner1` (поменять `banner1` для каждого креатива — будет видно в Метрике, какой работает)
   - **Кнопка**: «Забронировать» / «Подробнее» / «Подобрать дату»
7. Выбрать изображение/видео из библиотеки.
8. Сохранить → объявление уходит на модерацию.

Желательно добавить **5-10 объявлений** разных креативов — Yandex автоматически отберёт лучший по CTR.

### Затравочное текстовое объявление

После того как добавишь графику/видео — текстовое можно **остановить** (`State=OFF`) или **удалить**. Оно нужно было только чтобы кампания прошла создание (нельзя создать пустую AdGroup без хотя бы одного ad'а).

### После креативов — корректировки ставок

В AdGroup или Campaign добавить корректировки **через UI** (или через `BidModifiers.add` API):

| Сегмент | Корректировка | Зачем (из архивного анализа) |
|---|---:|---|
| Mobile | **−15%** | CPL на мобильных в 1.4× выше desktop |
| Desktop | **+20%** | CPL дешевле, основной канал бронирований |
| Возраст до 18 | **−100%** | Не платят |
| Возраст 25-44 | **+15%** | Целевая |
| Регион Москва (центр) | **+15%** | Чек выше |

В UI: кампания → «Корректировки» → выбрать тип → задать значения.
