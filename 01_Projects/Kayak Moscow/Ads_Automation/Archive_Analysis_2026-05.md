## 7 actionable выводов для сезона 2026

1. **CPL-таргет 900-1 000 ₽** (медиана исторически рабочих).
2. **Стартовать к 1 апреля** — окно дешёвых конверсий.
3. **Июль-август = 50% годового бюджета**.
4. **Октябрь-март — только ретаргетинг + микро-РСЯ**, поиск выключать.
5. **MOBILE −10..-15%, DESKTOP +20-25%** (особенно ретаргетинг).
6. **РСЯ + ретаргетинг масштабируются по CPL лучше поиска** — держать как основу.
7. **Не повторять `Осень v2`** — статистически чистый провал.

## Gaps (чего нет в данных)

1. **`SEARCH_QUERY_PERFORMANCE_REPORT` для архивных пустой** — Yandex обрезает по retention.
2. **Goal-level breakdown** — только агрегированные `Conversions`, без разбивки по целям Метрики.
3. **Stage funnel** (impr → click → landing → booking → payment) — Direct видит только до клика; полная картина появится с M9 offline conversions.
4. **Cost vs weather per campaign** — сейчас агрегировано по всем; per-campaign разрез — на M6.3 после ≥30 дней живых данных.
