Mobile-baseline нужно вшивать в weather curve в `ads_campaign_strategy` (правка кода в `KayakMoscow_ads`, отдельная задача).

## Новое знание про Direct API

**Подтверждено живой пробой 2026-06-08:** ЕПК для Telegram-канала и для сайта **создаётся через v501 API** с минимальным payload:

```python
POST /json/v501/campaigns method=add
{
  "Campaigns": [{
    "Name": "[2026] TG-Channel",
    "StartDate": "2026-06-15",
    "UnifiedCampaign": {
      "BiddingStrategy": {
        "Search":  {"BiddingStrategyType": "SERVING_OFF"},
        "Network": {
          "BiddingStrategyType": "WB_MAXIMUM_CLICKS",
          "WbMaximumClicks": {
            "WeeklySpendLimit": 7500000000,  # 7 500 ₽
            "BidCeiling": 60000000,           # 60 ₽
            "BudgetType": "WEEKLY_BUDGET"
          }
        }
      },
      "AdvertisedItem": {"Href": "https://t.me/kayakmoscow"}
    }
  }]
}
```

**Тестовая кампания `710566584` успешно создалась и удалена.**

**Валидные поля `UnifiedCampaign` (из API)**: `CounterIds`, `Settings`, `BiddingStrategy`, `PriorityGoals`, `TrackingParams`, `AttributionModel`, `PackageBiddingStrategy`, `CanBeUsedAsPackageBiddingStrategySource`, `NegativeKeywordSharedSetIds`, `AdvertisedItem`, `DefaultBusinessId`, `DefaultPhoneId`.

**Чего НЕТ через API:**
- Выбор «Места показа → Telegram-каналы + Max» — только UI (тумблер).
- Категории каналов — UI.
- Загрузка изображений в Библиотеку — UI.
- Выбор CTA-кнопки из пресета — UI.

**Грабли API, накопленные за сессию** (зафиксировано в [[reference-direct-api-quirks]] в памяти):

- `bidmodifiers/add` принимает плюрал (`DemographicsAdjustments`, `RegionalAdjustments`), `get` возвращает сингуляр. Асимметрия.
- `DemographicsAdjustments.Gender` не принимает `GENDER_ANY` — только `GENDER_MALE`/`GENDER_FEMALE` или `null`.
- `TimeTargeting.Schedule` коэффициенты кратны 10 (не 5).
- `MobileAdjustment` Campaign-level перебивается AdGroup-level. Hourly weather loop — это AdGroup-level, поэтому Campaign Mobile бесполезен на наших Бренд/Generic.
- `campaigns/get` v501 с UnifiedCampaign — типы полей: для ad'ов используется `ButtonExtension` (не `Button`), `BusinessId`, `SitelinkSetId`.
