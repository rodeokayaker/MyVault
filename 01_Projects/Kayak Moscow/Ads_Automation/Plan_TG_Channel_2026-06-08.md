# План кампании `[2026] TG-Channel` — продвижение @kayakmoscow в Telegram + Max

## TL;DR

ЕПК (UnifiedCampaign) с размещением «Реклама в Telegram-каналах и Max» через автоматический подбор каналов Yandex AI. Стратегия `WB_MAXIMUM_CLICKS` (фиксированная для этого формата), BidCeiling 60 ₽ — середина диапазона 30-300 ₽. Недельный лимит 7 500 ₽, бюджет на квартал 97 500 ₽ (≈40% от 240 000 ₽ ассигнованных на «Telegram через Я.Директ»). 2 варианта поста с разным эмоциональным посылом. KPI: **≥300 новых подписчиков за 90 дней, CPS ≤ 330 ₽**, CTR поста ≥ 0.5%. Через 30 дней — ревью с решением о масштабе.

**Существенная правка vs первый драфт (2026-06-08 v1):** изначально планировал TextCampaign с AVERAGE_CPC 12 ₽ — это неверно. Реальный продукт Yandex'а — это ЕПК со стратегией «Максимум кликов», минимум CPC 30 ₽. KPI пересмотрены под реальную экономику.

## Цель и контекст

**Что хотим:** Растить базу `@kayakmoscow` с текущих 1,21K до ≥1,5K к 1 октября. Канал — главный owned-media-актив (см. [[Исследование рекламного продвижения Kayak Moscow на сезон 2026#4 2 Telegram]]): прогрев, реактивация, weather-based анонсы слотов, социальные доказательства.

**Что это за продукт у Yandex:** «Реклама в Telegram-каналах» — отдельный формат внутри ЕПК. Объявление выглядит как пост в канале: до 764 символов текста, до 10 изображений или 1 видео ≤10 МБ, CTA-кнопка из пресетов, **автоматическая маркировка «Реклама» + ERIR-токен**. Пост живёт **48 часов**, потом удаляется автоматически. Yandex сам подбирает каналы по заданным тематикам и гео.

**Max добавлен в 2026** как часть того же inventory — отдельной настройки не требует, тумблер в UI кампании при выборе мест размещения.

**Почему не Telegram Ads напрямую:** TG Ads — другая площадка (евровая, минимальный депозит выше, без российского НДС). Через Я.Директ — рубли, ИП Рыбников И.Г., НДС, кабинет 62946101, единая экосистема с другими нашими кампаниями.

**Почему не сразу на сайт:** Отдельная парная кампания [[Plan_TG_Site_2026-06-08]] с другой воронкой (бронь, не подписка). Не смешиваем — разная экономика, разные KPI.

## Реальные ограничения формата (из официальной справки Я.Директа)

| Параметр | Значение |
|---|---|
| Тип кампании в API | `UNIFIED_CAMPAIGN` (v501 endpoint) |
| Стратегия | `WB_MAXIMUM_CLICKS` на Network, `SERVING_OFF` на Search (фиксированная) |
| Оплата | Только CPC, не CPM |
| CPC диапазон | 30-300 ₽ (минимум 30 ₽ — floor Yandex) |
| Минимальный недельный бюджет | 300 ₽ |
| Title | до 56 символов |
| Text | **до 764 символов** (с эмодзи, форматированием) |
| Изображения | до 10 шт., JPG/PNG, ≤10 МБ каждое, вертикальная ориентация рекомендуется, ≤1280×1280 px |
| Видео | 1 шт., ≤10 МБ, MP4 (опционально вместо изображений) |
| CTA-кнопка | только пресеты Yandex (нельзя кастомный текст) |
| Время жизни поста | 48 часов, потом автоудаление |
| Маркировка | автоматическая («Реклама» + ERIR-токен от Yandex) |
| Premium-фильтр | показы идут всем пользователям TG, включая Premium |
| Таргетинг | гео + тематики каналов (1+ из списка) + корректировки пол/возраст/платёжеспособность |
| Ручной выбор каналов | НЕТ в ЕПК-формате (только в охватных кампаниях с CPM — отдельный формат, см. ниже) |
| Исключение каналов | до 1 000 URL-исключений |

## Что доступно в API, что только в UI

**Через API (Codex может):**
- Создать скелет ЕПК (UnifiedCampaign) с `AdvertisedItem.Href=https://t.me/kayakmoscow`.
- Задать стратегию `WB_MAXIMUM_CLICKS` + `WeeklySpendLimit` + `BidCeiling`.
- `CounterIds` (Метрика 49922815).
- Settings: `ENABLE_SITE_MONITORING=YES` (хотя для TG-формата это менее критично), `ADD_METRICA_TAG=YES`.
- BidModifiers (демография, регион).

**Только через UI (владелец после создания):**
- Выбор «Места показа → Telegram-каналы + Max» (тумблеры — в Settings API такого Option нет; проверено пробами).
- Тематики каналов (1+).
- Загрузка изображений/видео в Библиотеку → привязка к объявлению.
- Выбор CTA-кнопки из пресетов.
- Финальный текст поста (если хочется быстро поправить — можно и через `ads/update` API, но удобнее в UI с превью).

**Проверено живой пробой 2026-06-08:** API `v501/campaigns/add` принял `AdvertisedItem.Href=https://t.me/kayakmoscow` с `Network.WB_MAXIMUM_CLICKS` без ошибок (тестовая кампания 710566584 создалась и удалена). Подтверждение: ЕПК для Telegram-канала **создаётся через API**.

## Конфигурация ЕПК

```yaml
name: "[2026] TG-Channel"
type: UNIFIED_CAMPAIGN     # API: v501 endpoint
client_login: kayakmoscow
start_date: 2026-06-15
advertised_item:
  href: https://t.me/kayakmoscow
strategy:
  search:
    type: SERVING_OFF
  network:
    type: WB_MAXIMUM_CLICKS
    weekly_spend_limit_micros: 7_500_000_000   # 7 500 ₽
    bid_ceiling_micros: 60_000_000             # 60 ₽ — потолок CPC
    budget_type: WEEKLY_BUDGET
metrika_counter_ids: [49922815]
settings:
  ENABLE_SITE_MONITORING: YES
  ADD_METRICA_TAG: YES
  SHARED_ACCOUNT_ENABLED: YES
default_business_id: 69769476747   # Я.Бизнес — для маркировки рекламодателя
```

### Настройки только в UI (владелец делает после создания скелета)

1. Места показа → выбрать «**Telegram-каналы**» + «**Max**» (новый тумблер 2026).
2. Тематики каналов (минимум 1, рекомендую 3-5):
   - Активный отдых и спорт
   - Путешествия и туризм
   - Москва и Подмосковье (локальные)
   - Лайфстайл
   - Семья и дети (по запросу)
3. Гео → Россия → область «Москва и Московская область» (или регионы 1).
4. Исключения каналов (опционально): добавить заведомо нерелевантные (политика, крипта, гэмблинг, медицина) — это снизит долю некачественного трафика. Список до 1 000 URL.

### Корректировки ставок (после создания, через API `bidmodifiers/add`)

| Тип | Значение | Зачем |
|---|---:|---|
| `DemographicsAdjustments`: Age=AGE_0_17 | 0 | дети не подписываются осознанно |
| `DemographicsAdjustments`: Age=AGE_25_34 | 115 | целевое ядро |
| `DemographicsAdjustments`: Age=AGE_35_44 | 115 | целевое ядро |
| `DemographicsAdjustments`: Age=AGE_45_54 | 110 | вторичный сегмент |
| `IncomeAdjustment` (платёжеспособность high) | 110 | +10% на сегмент «премиум» — выше LTV |
| `RegionalAdjustments`: RegionId=213 | 110 | город — выше AOV (когда подписчики бронируют) |

**Не задаём `MobileAdjustment`** — TG-аудитория mobile-first.

**Время:** в этом формате `TimeTargeting` менее значим (пост висит 48ч, не поминутный показ). Оставляем default «всегда».

## 2 варианта поста (A/B)

**Структура поста:** короткий заголовок-крючок (≤56) + основной текст с историей и call-to-action (300-500 символов используем из доступных 764). Эмодзи разрешены, но минимально (1-3 на пост, не больше). Без ★. Без множественных «!». Без caps-lock.

**Заголовок:** `Канал про водную Москву` (22)

Это не агрессивная реклама — это живой канал про каякинг, SUP и три базы в Москве и МО.

Подписывайся, если думал о выходных на воде.

**Изображение (квадрат 1080×1080):** каякер на закате на Москве-реке с видом на мост, в нижней трети — `@kayakmoscow` и логотип.

| Новые подписчики за 90 дней | 230-370 |

**Цель:** **≥300 подписчиков за 90 дней при CPS ≤ 330 ₽**.

**Бюджет кампании:** 97 500 ₽ за 90 дней (40% от 240 000 ₽ ассигнованных на «Telegram через Я.Директ» по [[Исследование рекламного продвижения Kayak Moscow на сезон 2026]]).

**Note про Москва-фактор:** по разбору в habr-статье (см. источники ниже), реклама ЕПК-TG в Москве «дороже, больше спам-инвентаря, ниже CR» чем регионы. Закладываемся в CPC 55-75 ₽, не 30-40 ₽.

## Трекинг подписок

Подписки в Telegram **не отслеживаются Я.Метрикой напрямую**. Используем 3 прокси:

1. **Клики по объявлению** — Я.Метрика видит через UTM на `t.me/kayakmoscow?utm_source=direct_tg&utm_campaign=tg_channel`. **Внимание:** UTM-метки в Telegram-ссылках Yandex иногда дропает. Альтернатива — использовать `t.me/kayakmoscow?start=direct_tg` с привязкой к боту, если есть.
2. **Прирост подписчиков** — снимать вручную через TGStat или штатной аналитикой Telegram. Baseline на старте — 1 210 (на 2026-06-08), фиксируем.
3. **Cross-check Yandex'овая аналитика** — отчёт «Места размещения» покажет переходы в канал по дням.

**KPI 90 дней:**
- **≥ 300 подписчиков прироста** (с 1 210 до 1 510 минимум).
- **CPS ≤ 330 ₽** (97 500 / 300 = 325 — впритык, нужен высокий CTR).
- **CTR постов ≥ 0.5%**.
- **Retention новых подписчиков 14 дней ≥ 60%** (не отписались за 2 недели).

## Запуск — что делает Codex (через API)

1. `campaigns/add` (endpoint v501) с конфигом выше: `AdvertisedItem.Href=https://t.me/kayakmoscow`, `Network.WB_MAXIMUM_CLICKS`, `WeeklySpendLimit=7_500_000_000`, `BidCeiling=60_000_000`.
2. Создание AdGroup через `adgroups/add` (тип группы должен быть автоматический для UnifiedCampaign — проверить ответ API).
3. `ads/add` 2 объявления (Ad #1, Ad #2) с текстами выше. **Внимание:** поле для длинного текста (764) и формат TG-поста через API — нужно проверить точное имя поля. По первоначальной разведке это `TelegramAd` или родственный subtype `TEXT_AD` с расширенным `Text`. Codex пробует, в случае неудачи — оставляет создание ads на UI.
4. `bidmodifiers/add` — 6 модификаторов (demographics + region + income — формат `*Adjustments` с S).

**Что Codex НЕ может (вне scope):**
- Выбор «Telegram + Max» в местах размещения — UI.
- Категории каналов — UI.
- Загрузка изображений в Библиотеку — UI.
- Выбор CTA-кнопки — UI (пресет).
- `campaigns/resume` — после модерации + после того как владелец завершит UI-настройки.

## Чек-лист приёмки (через 14 дней)

- Оба объявления Status=ACCEPTED + State=ON.
- CTR ≥ 0.3% (минимум для дальнейшего обучения).
- Расход в пределах 6 500-7 500 ₽/нед (≈лимит = инвентарь есть).
- Прирост подписчиков положительный по дням, согласован с откруткой.
- CPS первых 14 дней ≤ 450 ₽ (с запасом обучения).

Если ≥2 пункта FAIL — снизить `BidCeiling` до 50 ₽ или пересмотреть креатив.

## 30-дневный ревью

| Критерий | Зелёный (масштабируем 2×) | Жёлтый (держим) | Красный (стоп) |
|---|---|---|---|
| CPS | ≤ 250 ₽ | 250-350 ₽ | > 350 ₽ |
| CTR | ≥ 0.8% | 0.3-0.8% | < 0.3% |
| Подписчики за месяц | ≥ 130 | 70-130 | < 70 |
| Retention 14d | ≥ 70% | 50-70% | < 50% |

## Альтернатива (если ЕПК не зайдёт): охватные кампании

Если через 30 дней решение «красный» в ЕПК — переключиться на **охватные кампании с ручным выбором каналов** (отдельный формат Я.Директа, **CPM-оплата**, период 4-15 дней). Это позволит:
- Самостоятельно выбрать 3-5 нишевых каналов про Москву / активный отдых (через UI или биржу типа Telega.in).
- Гарантированный показ в качественных каналах.
- Понятный CPM (а не лотерея CPC).

Минусы: API для охватных кампаний не подтверждён, делать в UI вручную; меньше масштаб.

## Rollback

Если через 30 дней «красный» и охватный формат тоже не сработает:
1. `campaigns/suspend` через API.
2. Этот док помечается `status: archived`.
3. Доля 40% от TG-бюджета (97 500 ₽) переливается на [[Plan_TG_Site_2026-06-08]] или на ТК-автопилот.
