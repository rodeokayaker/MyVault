# Kayak — силовая конфигурация

## Суть

Эта заметка хранит фактическую силовую конфигурацию kayak-направления: водомёт, мотор, ESC, батарею и связанные ограничения. Её задача — быть hardware-реестром, а не размывать индексную заметку [[01_Projects/Smart Kayak/Kayak/Kayak|Kayak]].

## Фактическая силовая конфигурация каяка / водомёта

| Узел | Фактическая конфигурация | Примечание |
|---|---|---|
| Водомёт | MSQ 85 mm water jet / TILKIEA 085dd | Диаметр 85 мм |
| Мотор | SSS 56123 230KV | BLDC inrunner |
| ESC | FLIER SurfRider 300A OPTO | Programmable brushless motors ESC, LiPo 6–16S, no BEC |
| Батарея | 48В (12S) 55Ah | Уже куплена и используется |
| BMS | 150A | Верхнее напряжение ограничено программно |
| Диапазон батареи | 36–50.4 В | Фактический диапазон батареи |
| Ограничение заряда | До 48 В | Уже реализовано, минус ~5% доступной ёмкости |
| Зарядка | 50.4V 5A charger | Соответствует 12S Li-ion конфигурации |
| Ток заряда батареи | До 25 А | По данным из переписки по батарее |
| Масса батареи | ~16 кг | По фактической купленной сборке |
| Цена батареи | 84 370 ₽ | Цена покупки / сборки |

> [!WARNING] Несоответствие текущего мотора рекомендациям продавца
> По описанию продавца водомёта мотор **SSS 56123 230KV** для этого MSQ 85 mm считается слишком слабым / маленьким. Сам продавец рекомендует мотор порядка **9–10 кВт**, диапазон **100–180 KV**, питание **14S–20S LiPo** и ESC **300–400A**. Это нельзя игнорировать при оценке реальной тяги, эффективности и теплового режима.

> [!NOTE] По полю `KV1100` в карточке товара
> Поле `KV1100` не считать реальной характеристикой водомёта: это, скорее всего, мусорное шаблонное поле карточки.
