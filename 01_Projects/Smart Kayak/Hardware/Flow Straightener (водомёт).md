# Flow Straightener (водомёт)

Задача: подготовить к печати выпрямитель потока для каяка на водомёте.

## Требования 

- Увеличить деталь на **+5 см** (уточнить: по длине/вылету вдоль оси потока).
- Добавить **место посадки подшипника** (уточнить тип/размер подшипника и посадочные допуски).

## Что нужно уточнить перед моделированием

- [x] От какой версии/модели отталкиваемся (есть ли исходники: STEP/F3D/STL)? (Иван добавит завтра)
- [x] +5 см — это общая длина корпуса или расстояние до/после решётки?
- [x] Подшипник: тип (например 6000/608 и т.п.), внутренний/наружный диаметр, ширина. (уточнить у Сани)
- [x] Посадка: пресс/скользящая, материал печати (PETG/ABS/нейлон), нужен ли стопор (бурт/канавка/крышка).
- [x] Диаметр канала и геометрия лопаток/сот — чтобы не душить поток.

## План (черновик)

1) Забрать исходную геометрию / замеры.
2) В CAD:
   - удлинить на +50 мм по оси потока
   - добавить узел посадки подшипника (гнездо + упор/бурт)
   - проверить стенки/жёсткость под печать
3) Экспорт:
   - [x] STL (ориентация под печать)
   - [x] STEP (если Максу/печатнику удобнее)
1) Передать Максу:
   - [x] файлы
   - [x] краткие параметры печати (материал, % заполнения, ориентация)
