# SUP — системная архитектура

## Суть

Электро-SUP построен как модульная система из четырёх узлов:
1. [[01_Projects/Smart Kayak/Hardware/Батарея SUP — спецификация|Батарея]]
2. [[01_Projects/Smart Kayak/SUP/docs/SUP — контрол-бокс|Контрол-бокс]]
3. [[01_Projects/Smart Kayak/SUP/docs/SUP — Motor Dock|Motor Dock]]
4. [[01_Projects/Smart Kayak/SUP/docs/SUP — E-Fin|E-Fin]]

Принцип здесь правильный: пользователь снимает батарею и плавник, а силовая и интеграционная механика остаётся в борде.

## Схема модулей

| Модуль | Расположение | Интерфейс | Статус |
|---|---|---|---|
| Батарея | Палуба | 4 штыря: 2 силовых + 2 CAN | Съёмная |
| Контрол-бокс | Палуба | Кабель внутри борда, 4 провода | Стационарный |
| Motor Dock | Корма | Слот + pogo pins | Стационарный |
| E-Fin | Под водой | 3 фазы + GND + Signal | Съёмный |

```text
НОС
[Батарея]
   ↓
[Контрол-бокс]
   ↓
[Motor Dock]
   ↓
[E-Fin]
КОРМА
```

## Ключевые параметры системы

| Параметр | Значение |
|---|---|
| Мотор | 24 В, 600 Вт |
| Батарея | 7S10P, 21700, ~50 А·ч, ~1200 Вт·ч |
| Пиковый ток | ~29 А |
| Управление ESC | Servo PWM сейчас, DShot300 в v2 |
| Связь | BLE 5.0 на ESP32-S3 |
| Обновление | OTA |
| Защита | IP67 в сборе |

## Внутренняя проводка

| Параметр | Значение |
|---|---|
| Длина трассы | ~100 см |
| Линии | B+ / B− / GND / Signal |
| Силовые провода | 4 мм² |
| Сигнальные провода | 0.5 мм² |

Решение с длинной трассой терпимо, но только при аккуратной работе с помехами. Если оставаться на Servo PWM, скрутка GND+Signal и феррит — не роскошь, а минимум инженерной гигиены.

## Производственная логика

В борд интегрируются:
- [[01_Projects/Smart Kayak/SUP/docs/SUP — контрол-бокс|контрол-бокс]]
- [[01_Projects/Smart Kayak/SUP/docs/SUP — Motor Dock|Motor Dock]]
- кабельная трасса
- ТПУ-втулки
- точка носовой фиксации батареи

Это делает изделие более сервисным: пользователь меняет расходники, а завод отвечает за герметичную силовую интеграцию.
