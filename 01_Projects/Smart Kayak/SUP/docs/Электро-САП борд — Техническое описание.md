## Батарея

### Конфигурация

| Параметр | Значение |
|---|---|
| Формат ячейки | 21700 |
| Конфигурация | 7S10P |
| Напряжение | 24.5 В номинал / 29.4 В заряд / 21 В разряд |
| Ёмкость | ~50 А·ч |
| Энергия | ~1200 Вт·ч |
| Габариты корпуса | 550 × 220 × 30 мм |
| BMS | Встроенная, CAN bus |

### Крепление

Батарея фиксируется тремя уровнями:
1. штыревой разъём в контрол-бокс;
2. липучка по нижней плоскости;
3. магнитная защёлка или стропа в носовой части.

### Разъём батарея → контрол-бокс

| Пин | Назначение | Диаметр |
|---|---|---|
| B+ | Силовой плюс | ∅8 мм |
| B− | Силовой минус | ∅8 мм |
| CAN-H | Данные BMS | ∅2 мм |
| CAN-L | Данные BMS | ∅2 мм |

Принципиальное решение: несимметричное расположение штырей как защита от неверной установки.

## Контрол-бокс

| Параметр | Значение |
|---|---|
| Габариты | 50 × 180 × 20 мм |
| Материал | ABS + 15% стекловолокно |
| Крепление | ВЧ сварка к ПВХ палубе |
| Класс защиты | IP67 |
| Выравнивание давления | Gore‑Tex клапан ∅10 мм |
| Кабельный ввод | ТПУ втулка IP68 |

### Электроника

| Компонент | Модель | Назначение |
|---|---|---|
| MCU | ESP32-S3 | Управление, BLE, Wi‑Fi, OTA |
| Step-down | TPS54360 или аналог | 5 В / 3 А |
| IMU | BNO-08x | 9-axis, AHRS |
| GPS | u-blox TAU-1201 | Навигация и трекинг |

### Управление ESC

Текущая версия использует **Servo PWM 1000–2000 мкс**. Для v2 запланирован переход на **DShot300** как на более устойчивый и телеметрически полезный протокол.

## Внутренняя проводка

| Параметр | Значение |
|---|---|
| Длина трассы | ~100 см |
| Состав | B+ / B− / GND / Signal |
| Силовые провода | 4 мм² |
| Сигнальные провода | 0.5 мм² |
| Протокол | Servo PWM → DShot300 v2 |

Ключевое замечание: при длинном Servo PWM кабеле нужна скрутка GND+Signal и желательно феррит у входа в motor dock.

## Motor Dock

| Параметр | Значение |
|---|---|
| Корпус | Анодированный алюминий |
| Содержимое | ESC + слот E-Fin + pogo pins |
| Охлаждение ESC | Пассивное через корпус в воду |
| Тепловыделение | ~42 Вт при 600 Вт |
| Расчётный ΔT | ≤ 4.4 °C |
| Класс защиты | IP68 |

### Pogo pins

| Пин | Назначение | Диаметр | Макс. ток |
|---|---|---|---|
| Фаза A | BLDC мотор | 5–6 мм | 30 А |
| Фаза B | BLDC мотор | 5–6 мм | 30 А |
| Фаза C | BLDC мотор | 5–6 мм | 30 А |
| GND | Сигнальная земля | 2 мм | — |
| Signal | Servo PWM / DShot | 2 мм | — |

## E-Fin

| Параметр | Значение |
|---|---|
| Мотор | BLDC 24 В / 600 Вт |
| Высота плавника | 150–180 мм |
| Длина основания | 120–150 мм |
| Толщина основания | 35–50 мм |
| Материал | PA66-GF30 или карбон |
| Герметизация | Полная заливка компаундом |

Принципиальное решение: ESC вынесен в [[01_Projects/Smart Kayak/SUP/docs/Электро-САП борд — Техническое описание|Motor Dock]], а сам плавник делается максимально простым и заменяемым.

## EMI / помехи

| Сегмент | Сигнал | Длина | Риск |
|---|---|---|---|
| Батарея → контрол-бокс | DC | 0 | Нет |
| Контрол-бокс → Motor Dock | DC + Servo PWM | ~100 см | Низкий |
| ESC → мотор | 3-фазный PWM | ~5 см | Практически отсутствует |

Главное инженерное решение здесь здравое: самый грязный по помехам участок укорочен до ~5 см и убран внутрь алюминиевого корпуса.

## Производственная интеграция

Интегрируются в борд:
- motor dock;
- две ТПУ-втулки;
- внутренний 4-проводный кабель;
- контрол-бокс;
- точка носовой фиксации батареи.

Последовательность сборки:
1. раскрой ПВХ и отверстий;
2. вварка втулок, motor dock и D-кольца;
3. протяжка кабеля;
4. склейка полотен;
5. приварка контрол-бокса;
6. подключение к плате и закрытие корпуса.

## Оценка

Документ уже не пустая болтовня, а добротный концепт уровня системного эскиза. Сильные стороны — модульность, ремонтопригодность, продуманная логика EMI и здравое разделение пользовательских и заводских узлов. ## 1. Обзор системы

Настоящий документ описывает архитектуру электрической и механической систем надувного САП борда с электроприводом. Система разработана с акцентом на модульность, безопасность, ремонтопригодность и удобство использования.

> [!NOTE] Ключевая концепция
> Система разделена на четыре независимых модуля: **Батарея → Контрол-бокс → Motor Dock → E-Fin**. Батарея и E-Fin — съёмные пользовательские элементы. Контрол-бокс и Motor Dock интегрированы в борд при производстве.

### 1.1 Структурная схема

| Модуль | Расположение | Интерфейс вниз | Статус |
|--------|-------------|----------------|--------|
| Батарея | Палуба, надевается на контрол-бокс | 4 штыря (2 силовых + 2 CAN) | Съёмная |
| Контрол-бокс | Палуба, приварен к борду | Кабель внутри борда (4 пр.) | Стационарный |
| Motor Dock | Корма, интегрирован в борд | Проприет. слот + pogo pins | Стационарный |
| E-Fin | Слот Motor Dock, под водой | Pogo pins (3 фазы + GND + Signal) | Съёмный |

```text
        НОС БОРДА
            ▲
            │
  ┌─────────────────────┐
  │   ┌─────────────┐   │
  │   │             │   │
  │   │  БАТАРЕЯ    │   │  55см × 22см
  │   │             │   │
  │   └──────┬──────┘   │
  │          │          │
  │   ┌──────┴──────┐   │
  │   │ КОНТРОЛ-БКС │   │  5см × 18см
  │   └─────────────┘   │
  │          │          │
  │     [MOTOR DOCK]    │
  │          │          │
  │       [E-FIN]       │
            ▼
        КОРМА БОРДА
```

> [!WARNING] Servo PWM → DShot: план перехода
> Текущая версия использует Servo PWM (ESC уже имеется). Для v2 — переход на **DShot300**: цифровой, не требует калибровки, устойчив к помехам, поддерживает телеметрию. При кабеле ~100 см рекомендуется скрутка GND+Signal.
