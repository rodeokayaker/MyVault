## 1. Обзор системы

Настоящий документ описывает архитектуру электрической и механической систем надувного САП борда с электроприводом. Система разработана с акцентом на модульность, безопасность, ремонтопригодность и удобство использования.

> [!NOTE] Ключевая концепция
> Система разделена на четыре независимых модуля: **Батарея → Контрол-бокс → Motor Dock → E-Fin**. Батарея и E-Fin — съёмные пользовательские элементы. Контрол-бокс и Motor Dock интегрированы в борд при производстве.

### 1.1 Структурная схема

| Модуль | Расположение | Интерфейс вниз | Статус |
|--------|-------------|----------------|--------|
| Батарея | Палуба, надевается на контрол-бокс | 4 штыря (2 силовых + 2 CAN) | Съёмная |
| Контрол-бокс | Палуба, приварен к борду | Кабель внутри борда (4 пр.) | Стационарный |
| Motor Dock | Корма, интегрирован в борд | Проприет. слот + pogo pins | Стационарный |
| E-Fin | Слот Motor Dock, под водой | Pogo pins (3 фазы + GND + Signal) | Съёмный |

```
        НОС БОРДА
            ▲
            │
  ┌─────────────────────┐
  │   ┌─────────────┐   │
  │   │             │   │
  │   │  БАТАРЕЯ    │   │  55см × 22см
  │   │             │   │
  │   └──────┬──────┘   │
  │          │          │
  │   ┌──────┴──────┐   │
  │   │ КОНТРОЛ-БКС │   │  5см × 18см
  │   └─────────────┘   │
  │          │          │
  │     [MOTOR DOCK]    │
  │          │          │
  │       [E-FIN]       │
            ▼
        КОРМА БОРДА
```

### 2.2 Геометрия корпуса

| Параметр | Значение |
|----------|----------|
| Габариты | 490 × 210 × 21 мм |
| Ориентация | Вдоль борда, по центру палубы |
| Позиция | Кормовым краем надевается на контрол-бокс |

### 2.3 Крепление к борду

Батарея фиксируется тремя способами одновременно:

- **Штыревой разъём** — кормовой край надевается на контрол-бокс, 4 штыря входят в гнёзда автоматически. Штыри центруют батарею.
- **Липучка (велкро)** — по всей нижней плоскости. Вспомогательная фиксация (намокает, теряет усилие).
- **Магнитная защёлка или стропа** — у носового края. Предотвращает случайный подъём при манёврах.

> [!TIP] Механика укладки
> 1. Кормовой край навести на бокс (фаски на штырях, допуск ±3мм)
> 2. Опустить — штыри вошли, липучка зафиксировала
> 3. Зафиксировать носовой край магнитом или стропой
> 
> Разъём подключён автоматически при укладке.

### 2.4 Разъём батарея → контрол-бокс

```
        ВИД СПЕРЕДИ (поперёк борда)

        ←────── 22см ──────→
  ┌─────────────────────────┐
  │        БАТАРЕЯ          │  30мм
  │  [○]               [○] │  ← гнёзда
  └──┼─────────────────┼───┘
     │                 │
  ───●─────────────────●───  ← верх бокса (штыри вровень)
  ╔══╧═════════════════╧══╗
  ║     КОНТРОЛ-БОКС      ║  20мм
  ║       18см            ║
  ╚═══════════════════════╝
```

| Пин | Назначение | Диаметр | Расположение |
|-----|-----------|---------|-------------|
| B+ | Силовой плюс | ∅8 мм | Левый край, смещён (дурозащита) |
| B− | Силовой минус | ∅8 мм | Правый край |
| CAN-H | Данные BMS | ∅2 мм | Рядом с B+, левый край |
| CAN-L | Данные BMS | ∅2 мм | Рядом с B−, правый край |

> [!NOTE] Дурозащита
> Несимметричное расположение штырей (∅8мм и ∅2мм в разных углах) исключает неправильную ориентацию батареи. Конусные фаски обеспечивают самонаведение.

### 2.5 Герметизация разъёма

- **Резиновая мембрана** внутри каждого гнезда — основная герметизация (принцип медицинского порта)
- **Резиновая юбка** у основания штыря — вторичный барьер
- В сборе: **IP67** / Штыри без батареи: IP54

### 3.1 Геометрия и расположение

```
        ВИД СБОКУ (вдоль борда)

  НОС ──────────────────────────── КОРМА
```

### 3.2 Кнопка и индикатор

Расположены на **торце бокса (в сторону кормы)** — доступны всегда, батарея не перекрывает.

| Элемент | Тип |
|---------|-----|
| Кнопка | Металлическая встраиваемая с уплотнением (Apem / EAO / Schurter) |
| RGB индикатор | Кольцевой LED-обод вокруг кнопки |

### 3.3 Электроника

| Компонент | Модель | Назначение |
|-----------|--------|-----------|
| MCU | ESP32-S3 | Управление, BLE 5.0, WiFi, OTA |
| Step-down | TPS54360 или аналог | 5В/3А для логики |
| IMU | BNO-08x | Акселерометр + гироскоп + магнитометр, 9-axis, I2C, AHRS |
| GPS | u-blox TAU-1201 | Навигация, трекинг маршрута |

> [!NOTE] Почему BNO-08x
> Встроенный алгоритм AHRS даёт абсолютный курс (не только относительный). Магнитометр + акселерометр + гироскоп на одном чипе. Для трекинга маршрута в связке с GPS — оптимально.

> [!NOTE] GPS и BLE антенны
> Крышка бокса — ABS или поликарбонат **без металла и карбона**. Патч-антенна GPS приклеена к верхней стенке изнутри. Металл и карбон в крышке экранируют сигнал — недопустимы.

### 3.6 OTA обновление прошивки

- Приложение на телефоне обнаруживает бокс по BLE

## 4. Внутренняя проводка борда

### 4.1 Кабельная трасса

| Параметр | Значение |
|----------|----------|
| Длина | ~100 см (центр → корма) |
| Состав | 4 провода: B+ / B− / GND / Signal |
| Сечение силовых | 4 мм² (B+, B−) |
| Сечение сигнальных | 0.5 мм² (GND, Signal) |
| Протокол | Servo PWM (→ DShot300 в v2) |
| Экранирование | Скрутка GND+Signal при Servo PWM |
| Разъёмы по трассе | Нет — цельный кабель |

### 4.2 Герметичные кабельные вводы

| Точка | Расположение | Тип | IP |
|-------|-------------|-----|----|
| Выход из бокса | Дно бокса → ПВХ палуба | ТПУ втулка + PG7 гайка | IP68 |
| Вход в Motor Dock | ПВХ палуба → корпус дока | ТПУ втулка вварная | IP68 |

> [!NOTE] Давление в борде vs нагрузка на втулку
> Давление накачки 0.15–0.2 бар. Усилие на втулку ∅15мм — **~350 грамм**. PG втулка держит 50+ кг. Реальный риск — герметичность шва, а не прочность. ТПУ сваривается с ПВХ борда монолитно — это решение.

## 5. Motor Dock

### 5.1 Конструкция

| Параметр | Значение |
|----------|----------|
| Корпус | Анодированный алюминий |
| Крепление | Фланец, вулканизация к ПВХ борда |
| Содержимое | ESC + проприетарный слот E-Fin + pogo pins |
| Расположение ESC | В корпусе, залит теплопроводящим компаундом |
| Охлаждение ESC | Пассивное, через алюминиевую стенку в воду |
| Тепловыделение при 600 Вт | ~42 Вт (КПД ~93%) |
| Расчётный ΔT | ≤ 4°C при ходе 5 км/ч |
| Класс защиты | IP68 |

### 5.2 Тепловой расчёт ESC

```
Мощность:         600 Вт
КПД ESC:          ~93%
Тепловыделение:   ~42 Вт

Площадь дна:      150 × 80 мм = 120 см²
Теплоотдача:      ~800 Вт/м²·К (ход 5 км/ч)

ΔT = 42 / (0.012 × 800) = 4.4°C  ✅  с большим запасом
```

### 5.3 Установка E-Fin (рельс + защёлка)

1. Передний край плавника — в носовой рельс слота
2. Кормовой край опускается — pogo pins касаются площадок
3. Фиксация: винт M5 или металлическая защёлка

### 5.4 Система pogo pins

| Пин | Назначение | Диаметр | Макс. ток |
|-----|-----------|---------|-----------|
| Фаза A | BLDC мотор, фаза A | 5–6 мм | 30 А |
| Фаза B | BLDC мотор, фаза B | 5–6 мм | 30 А |
| Фаза C | BLDC мотор, фаза C | 5–6 мм | 30 А |
| GND | Сигнальная земля | 2 мм | — |
| Signal | Servo PWM / DShot от MCU | 2 мм | — |

Длина PWM кабеля ESC → pogo pins: **~5 см** — EMI исключена.

> [!NOTE] Герметизация пустого слота
> При снятом E-Fin — самозакрывающиеся резиновые шторки над pogo pins (аналог Apple Watch). При установке плавника шторки отжимаются основанием.

## 7. Электромагнитная совместимость (EMI)

| Сегмент | Тип сигнала | Длина | EMI риск |
|---------|------------|-------|----------|
| Батарея → контрол-бокс | DC | 0 (прямой контакт) | Нет |
| Контрол-бокс → Motor Dock | DC + Servo PWM | ~100 см | Низкий (скрутка) |
| ESC → мотор (внутри дока) | 3-фазный PWM | ~5 см | Нет |

> [!WARNING] Servo PWM на длинном кабеле
> Аналоговый сигнал чувствителен к помехам. Рекомендуется: (1) скрутка GND+Signal, (2) минимальная петля, (3) феррит у входа в Motor Dock. DShot300 в v2 снимает проблему полностью.

> [!NOTE] Ключевое решение
> 3-фазный PWM кабель (ESC→мотор) — главный источник EMI. Здесь его длина **~5 см** внутри алюминиевого корпуса. Наводки на GPS и BLE исключены.

## 8. Производство борда

### 8.1 Интегрируемые элементы

| Элемент | Позиция | Технология |
|---------|---------|-----------|
| Motor Dock (алюминий) | Корма, дно борда | Фланец, вулканизация к ПВХ |
| ТПУ втулка #1 | Под боксом, центр | ВЧ сварка |
| ТПУ втулка #2 | Вход в Motor Dock | ВЧ сварка |
| Кабель (4 провода) | Центр → корма | Закладывается до склейки |
| Контрол-бокс | Поперёк борда, центр | ВЧ сварка по периметру |
| D-кольцо / пластина | Носовой край зоны батареи | Для стропы или магн. защёлки |

### 8.2 Последовательность сборки

1. Раскрой ПВХ, вырезка отверстий
2. Вварить ТПУ втулки, Motor Dock, D-кольцо в **нижнее** полотно
3. Протянуть кабель: втулка #2 (корма) → втулка #1 (центр)
4. Склейка верхнего и нижнего полотна — кабель внутри
5. Приварить контрол-бокс — кабель выходит через втулку #1 внутрь бокса
6. Подключить кабель к плате, закрыть корпус
