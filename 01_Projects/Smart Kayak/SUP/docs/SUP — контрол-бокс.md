# SUP — контрол-бокс

## Роль

Контрол-бокс — центральный надпалубный узел, который соединяет батарею, внутреннюю проводку борда и управляющую электронику.

## Геометрия и установка

| Параметр | Значение |
|---|---|
| Габариты | 50 × 180 × 20 мм |
| Ориентация | Поперёк борда |
| Материал | ABS + 15% стекловолокно |
| Крепление | ВЧ сварка к ПВХ палубе |
| Класс защиты | IP67 |
| Давление | Gore-Tex клапан ∅10 мм |
| Кабельный ввод | ТПУ втулка IP68 |

Батарея надевается на бокс кормовым краем. Кнопка и LED вынесены на торец в сторону кормы — это здраво: доступ не перекрывается батареей.

## Интерфейс с батареей

| Пин | Назначение | Диаметр |
|---|---|---|
| B+ | Силовой плюс | ∅8 мм |
| B− | Силовой минус | ∅8 мм |
| CAN-H | Данные BMS | ∅2 мм |
| CAN-L | Данные BMS | ∅2 мм |

Ключевое решение: несимметричное расположение штырей как защита от ошибочной установки.

## Электроника

| Компонент | Модель | Назначение |
|---|---|---|
| MCU | ESP32-S3 | Управление, BLE, Wi‑Fi, OTA |
| Step-down | TPS54360 или аналог | 5 В / 3 А |
| IMU | BNO-08x | AHRS, курс, ориентация |
| GPS | u-blox TAU-1201 | Трекинг и навигация |

## Управление и интерфейс

### Кнопка
- металлическая герметичная кнопка;
- кольцевой RGB LED вокруг кнопки;
- расположение: торец бокса в сторону кормы.

### Прошивка
- BLE-обнаружение с телефона;
- OTA через вторую партицию flash;
- обновление 2–3 минуты без кабеля.
