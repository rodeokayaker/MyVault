# SUP — E-Fin

## Роль

E-Fin — съёмный электрический плавник с мотором и движителем. По замыслу это должен быть максимально простой и заменяемый узел, то есть почти расходник, а не сакральная деталь, которую страшно трогать.

## Параметры

| Параметр | Значение |
|---|---|
| Мотор | BLDC 24 В / 600 Вт |
| Высота плавника | 150–180 мм |
| Длина основания | 120–150 мм |
| Толщина у основания | 35–50 мм |
| Материал | PA66-GF30 или карбон |
| Герметизация | Полная заливка компаундом |
| Контакты | 5 позолоченных площадок |

## Интерфейс

Контакты:
- 3 силовые фазы
- GND
- Signal

Сама логика хороша: ESC вынесен в [[01_Projects/Smart Kayak/SUP/docs/SUP — Motor Dock|Motor Dock]], поэтому плавник можно упростить, удешевить и сделать заменяемым пользователем.

## Ключевые инженерные вопросы

### Гидродинамика
Пока это главный пробел. Без формы и гидродинамики E-Fin вся система остаётся красивой архитектурной схемой, но не гарантированно хорошим изделием.

### Крыльчатка
Нужно определить:
- [ ] диаметр
- [ ] шаг
- [ ] материал
- [ ] компромисс между тягой, шумом и безопасностью

### Крепление
Нужно проверить:
- [ ] надёжность фиксации в слоте
- [ ] удобство установки руками в воде
- [ ] защиту от люфта и коррозии контактов

## Следующий смысловой шаг

Нужна отдельная заметка по движителю: форма плавника, тип крыльчатки, режимы тяги, шум, кавитация, безопасность для пользователя и мелководья.
