# Kayak

Контроллер SmartKayak, который принимает данные умного весла и преобразует их в команду мотору.

## Goal

Стабильное, безопасное и предсказуемое управление тягой в реальном времени.

## Scope

- BLE-клиент к SmartPaddle
- режимы мощности: `OFF/LOW/MED/HIGH/DEBUG`
- ForceAdapter + StrokeForceController
- предиктивный режим: `PredictedPaddle + StrokePredictorGrid`
- логирование телеметрии для анализа и тюнинга

> [!WARNING] Несоответствие текущего мотора рекомендациям продавца
> По описанию продавца водомёта, мотор **SSS 56123 230KV** для этого MSQ 85 mm считается слишком слабым / маленьким. Сам продавец рекомендует мотор порядка **9–10 кВт**, диапазон **100–180 KV**, питание **14S–20S LiPo** и ESC **300–400A**. Это нужно учитывать при оценке реальной эффективности, тяги и теплового режима текущей конфигурации.

> [!NOTE] По полю `KV1100` в карточке товара
> Поле `KV1100` из карточки маркетплейса не считать реальной характеристикой водомёта: это, скорее всего, мусорное / шаблонное поле карточки товара.
